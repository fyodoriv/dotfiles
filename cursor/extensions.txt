# Cursor extensions — managed by dotfiles
# Source of truth for `modules/cursor/doctor.sh`. One extension ID per line.
# Lines starting with `#` and blank lines are ignored.
#
# To add/remove: edit this file, run `dotfiles-doctor --fix --module cursor`.
# The doctor installs missing extensions only; existing local extensions stay.
#
# Layered to match the same WebStorm/Ghostty parity goal as windsurf/extensions.txt,
# while keeping Cursor's first-party AI surface owned by Cursor/agentbrew.
