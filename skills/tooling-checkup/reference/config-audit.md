# Agent config audit (Phase 7)

Check the user's skills, rules, and instruction files against Anthropic's
published guidance. A script checks the mechanical rules. You check the rest.

## Sources

Fetch these when the run starts. When a page changed a rule, follow the page
and update this file and the script.

- Skill authoring best practices:
  `https://docs.claude.com/en/docs/agents-and-tools/agent-skills/best-practices`
- Claude Code skills: `https://code.claude.com/docs/en/skills`
- Claude Code memory and CLAUDE.md: `https://code.claude.com/docs/en/memory`
- Claude Code subagents: `https://code.claude.com/docs/en/sub-agents`

Append `.md` to a docs URL to get Markdown. When `WebFetch` refuses the host,
use `curl -sL <url>.md`.

## Script checks

```bash
python3 <skill-dir>/scripts/audit_agent_config.py --cache
python3 <skill-dir>/scripts/audit_agent_config.py --include-installed   # third-party, report only
```

`--cache` replays the last result when no input file changed.

## Judgment checks

Read each finding. Then check what a script cannot:

- **Specific descriptions.** The description names concrete triggers and key
  terms. Two skills must not claim the same triggers.
- **Concise instructions.** Each always-loaded line earns its place. Move
  detail that matters only for some tasks into a skill or a path-scoped rule.
- **No duplication across always-loaded files.** One rule lives in one source.
  `~/.claude/CLAUDE.md` is generated by agentbrew from the shared rules and
  the Agentfile `rules:` block. A line in both sources appears twice in the
  output. Fix the duplicate at the source.
- **Hard rules belong in hooks.** A rule that must never break ("never
  `--no-verify`") is a PreToolUse hook, not only prose.
- **Subagents.** Each agent file has a focused `description` and only the
  tools it needs.
- **Side-effect skills.** A skill that pushes, deletes, or upgrades sets
  `disable-model-invocation: true`, so only the user starts it.

## Where to fix

| File | Source to edit |
|---|---|
| `~/.claude/CLAUDE.md`, `~/.claude/skills/*` | Generated. Edit `~/.config/agentbrew/shared-rules.md`, the dotfiles `Agentfile.yaml`, or the skill's source repo. Then `agentbrew sync`. |
| Skills in a tooling repo | That repo. Deliver with `/ship-it`. |
| `~/.config/agentbrew/installed-skills/*` from third-party sources | Report only. Fix upstream if the user asks. |

Small fixes (a broken link, a missing "Use when", a repeated line) ship in one
pull request per repo. Big changes (splitting a long `AGENTS.md`, removing a
rule, merging skills) go to the questionnaire.
