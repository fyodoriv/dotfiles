# Windsurf extensions — managed by dotfiles
# Source of truth for `modules/windsurf/doctor.sh`. One extension ID per line.
# Lines starting with `#` and blank lines are ignored.
#
# To add/remove: edit this file, run `dotfiles-doctor --fix`. The doctor module
# calls `windsurf --install-extension <id>` for missing entries; existing
# extensions stay untouched (no churn, no version pin needed here).
#
# Do NOT pin versions — Windsurf's update.mode=manual + extensions.autoUpdate=false
# in settings.json already prevent surprise updates. Pin only if you hit a regression.
#
# Layer rationale: each block replaces a specific WebStorm built-in.
